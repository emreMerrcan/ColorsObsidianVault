## TAKING KEYWORDS

Keywords are strictly tied to roleplay and backstories, so the DM must allow if one can be taken. They do not require xp to be spent to be taken, rather certain progress thresholds must be met. A character is entitled to a new Keyword every 1000XP's they gather. (By this logic, get a keyword slot for each thousand xp + 3)

While choosing Keyword Types a healthy ratio looks like this:
4 Background, 2 Feature, 1 Combat

Other keywords better taken once or twice per character, not more. Proficiency Keywords can be given more plenty, while playstyle defining ones are spared. Also if a player willingly wants to take a negative Keyword, this might not take a slot.
