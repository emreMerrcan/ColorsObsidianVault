# REPULSION

Push the target entity or object as if you were right beside them, and get repelled in return. You can magnify the force of pushing for one of the sides by spending extra essence. For every 2 extra ESNC, the push force gets doubled. 

Spend Essence to:
0, topple a loaded bucket
1, push a person off balance
2, push to shove a person
4, push to knock a bear
6, push to shove a bear
8, push to knock a car
10, push to throw a car
12, push to breake a building
14, push to throw a building
16, push to create an impact crater
18, push to earthquake
20, push to earthquake mag 8?

MILESTONES:
-If the extra repulsion is to effect both sides, it would take another extra ESNC.

-For an AoE conversion, use the cone extras.

-1 ESNC to make the level 0 push a turn long thing for every interaction, (like using it to push the ground every step... to sky walk)

-1 ESNC to do the push with an object instead of your body (like an axe...)

- A parallel tree for attraction basically
